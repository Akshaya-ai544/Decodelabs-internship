SQL Data Analysis Project

Project Overview

This project analyzes sales data using SQL. The objective is to extract meaningful insights from the dataset using SQL queries and aggregation functions.

Dataset

The dataset contains order details such as:

- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Payment Method
- Order Status
- Total Price

SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()

Queries Performed

1. Display all records
2. Count total orders
3. Calculate total revenue
4. Find average order value
5. Analyze revenue by product
6. Analyze orders by payment method
7. Analyze orders by status

Key Insights

- Identified top-performing products.
- Analyzed customer payment preferences.
- Calculated total revenue and average order value.
- Examined order status distribution.
