# Exploratory Data Analysis Dashboard (Excel)

## Overview
This project performs Exploratory Data Analysis (EDA) using Microsoft Excel and presents insights through an interactive dashboard.

## Features
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Interactive Slicer
- Dashboard Creation

## Dashboard Visualizations
- Total Sales by Category
- Order Status Distribution
- Sales by Payment Method

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
